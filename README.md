# 🐻 BearDo - Aprenda Idiomas com IA

Um aplicativo moderno e interativo para aprendizado de idiomas, inspirado no Duolingo, com integração de IA para gerar exercícios personalizados e feedback inteligente.

## ✨ Características

- 🎯 **Exercícios Interativos**: Tradução, múltipla escolha, digitação e listening
- 🤖 **IA Inteligente**: Geração automática de exercícios e feedback personalizado
- 🎮 **Gamificação**: Sistema de XP, níveis, streaks e conquistas
- 🎨 **UI Moderna**: Interface bonita e intuitiva com Material-UI
- 📊 **Acompanhamento de Progresso**: Dashboard completo com estatísticas

## 🚀 Como Executar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Abra o navegador em `http://localhost:5173`

## 🛠️ Tecnologias

- **React 18** - Biblioteca UI
- **TypeScript** - Tipagem estática
- **Vite** - Build tool rápida
- **Material-UI** - Componentes de UI
- **Emotion** - Estilização CSS-in-JS

## 📝 Scripts Disponíveis

- `npm run dev` - Inicia servidor de desenvolvimento
- `npm run build` - Cria build de produção
- `npm run preview` - Preview do build de produção
- `npm run lint` - Executa o linter
